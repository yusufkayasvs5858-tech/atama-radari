4 Adımda Sıfır Maliyetli (0 TL) Tam Otomatik Kurulum Rehberi

  1. Telefonunuza ntfy Uygulamasını Kurun: Play Store veya App Store'dan ücretsiz ntfy uygulamasını indirin, + simgesine basıp atama-radari-p94-7808 konusuna abone olun.
  2. Ücretsiz GitHub Deposu Oluşturun: GitHub'da herkese açık (Public) bir depo açın; bu sayfanın HTML dosyasını index.html adıyla, indirdiğiniz scraper.js, package.json ve ilanlar.json dosyalarını ana dizine, radar.yml dosyasını ise .github/workflows/radar.yml yoluna yükleyin.
  3. GitHub Pages ve Actions'ı Etkinleştirin: Depo ayarlarından Pages → Deploy from branch (main) ve Actions → Read and write permissions seçeneklerini açın. Böylece robot her gün 08:00, 13:00 ve 19:00'da otomatik çalışıp ilanlar.json dosyasını günceller ve telefonunuza bildirim gönderir.
  4. Alternatif Yerel Windows Seçeneği: GitHub kullanmak istemezseniz bilgisayarınızda bir klasöre scraper.js ve package.json dosyalarını koyup terminalde npm install && node scraper.js çalıştırabilir, Windows Görev Zamanlayıcı'ya ekleyebilirsiniz. Onayınız olmadan hiçbir ücretli servis açılmaz.
